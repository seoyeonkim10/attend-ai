학생증 바코드 인증

카메라 인식 테스트

학생증의 세로줄 바코드를 비춰 주세요

카메라 권한을 허용하면 CODE 128, CODE 39, EAN 등 일반 바코드를 읽습니다.

현재 단계는 바코드 값 읽기 테스트입니다. 읽은 값은 출석으로 저장되지 않으며, 학생 계정과 학번을 안전하게 연결한 뒤 출석 처리 기능을 추가합니다.

학생증 미소지 대체 확인

학생증이 없는 경우, 교사가 학생의 신원을 확인한 뒤 임시 출석 요청을 등록합니다. 교사 승인이 완료되기 전에는 출석이 확정되지 않습니다.

안전 안내: 실제 운영에서는 교사 계정 권한 확인과 감사 로그가 필요합니다. 이 프로토타입은 인증 요청을 실제 서버에 저장하지 않습니다.
