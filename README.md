# ATTEND AI — 출결 관리 웹사이트 프로토타입

학교 맞춤형 AI 출결 관리 서비스의 정적 프런트엔드 데모입니다.

## 실행
`index.html` 파일을 브라우저에서 열면 됩니다.

## 포함 기능
- 반응형 대시보드
- 교사/학생 미리보기 전환
- 가상 출결 기록 검색 및 필터
- CSV 내보내기
- QR 인증 시뮬레이션
- 대체 인증 요청 시뮬레이션
- 결석·지각 신청 및 출결 정정 요청 시연
- AI 검토 항목 미리보기

## 중요
이 프로젝트는 **프로토타입**입니다. 로그인/권한 관리, 실제 QR 카메라 스캔, 데이터베이스, 파일 업로드, AI API 연결은 구현되어 있지 않습니다. 모든 학생 기록은 가상 데이터입니다. 실제 학생 개인정보를 넣지 마세요.

GitHub Pages에 게시하려면 `index.html`을 저장소 최상위에 업로드한 다음:
**Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**
를 선택하세요.
